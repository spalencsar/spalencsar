## Featured Projects

Active personal projects with a focus on practical, well-integrated Linux tooling.

### Linux Desktop Applications

**[Bearwave](https://github.com/spalencsar/bearwave)** — *Active*  
A focused, KDE-native internet radio application built with Qt 6, QML, and KDE Frameworks. Designed for clean Plasma integration, MPRIS support, system tray operation, and minimal resource usage. Prioritizes predictable behavior and maintainability over feature breadth.

- Primary target: KDE Plasma 6 on Arch Linux
- Bilingual UI (English / German)
- Available via AUR as `bearwave-git`
- [Repository](https://github.com/spalencsar/bearwave) · [Demo Video](https://github.com/spalencsar/bearwave/raw/main/screens/bearwave_demo.mp4)

**[Bearhub](https://github.com/spalencsar/bearhub)** — *Active*  
A community-maintained, Arch-first fork of bauh. Focused on long-term compatibility with modern Arch Linux and current Python versions. Provides a graphical interface for managing Arch packages (including AUR), Flatpak, AppImage, and web applications, with strong emphasis on stability and ongoing maintenance.

- Primary distribution: Arch Linux via AUR (`bearhub` / `bearhub-git`)
- [Repository](https://github.com/spalencsar/bearhub)

**[Deskify](https://github.com/spalencsar/deskify)** — *Active*  
A lightweight, CLI-first utility for converting web applications into native Linux desktop applications. Leverages the system WebView via Tauri or existing Chromium browsers to deliver strong desktop integration with substantially lower overhead than Electron-based wrappers. Available via AUR as `deskify-bin`.

- [Repository](https://github.com/spalencsar/deskify)
